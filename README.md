# Word Club

An original collection of nineteen word games plus a private birthday/family space.
Built from the specification pack in `reference/build-pack-v3/` (see `AGENTS.md`).

```sh
pnpm install
pnpm dev            # http://localhost:3000
pnpm lint && pnpm typecheck && pnpm test && pnpm validate:content && pnpm build && pnpm test:e2e
```

Status: all 19 games are playable practice previews; see `docs/COMPLETION-REPORT.md` first, then `docs/STATUS.md` for per-game readiness, `docs/DECISIONS.md` for
decisions and `docs/REVIEW-LOG.md` for everything that still needs a human check.
No game is production-enabled: editorial review, calibrated content banks and observed pilots are open gates.
